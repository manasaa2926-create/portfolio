# Manasa M - Portfolio

## Open in VS Code
1. Unzip the folder, then in VS Code choose File > Open Folder.
2. Install the "Live Server" extension, right-click index.html and choose "Open with Live Server".

## Add your files
- Photo: images/photo.jpg
- Resume: resume/Manasa_M_Resume.pdf

## Get a public link (free)
- Netlify Drop: go to app.netlify.com/drop and drag this whole folder onto the page.
- GitHub Pages: upload the folder to a GitHub repository, then Settings > Pages > deploy from the main branch.
